# E-Commerce Product Management System

## Description
A Django-based product management system with authentication
and CRUD functionality.

## Features
- User registration
- User login/logout
- Product creation
- Product listing
- Product updating
- Product deletion

## Technologies
- Python
- Django
- SQLite
- HTML
- CSS

## Setup
1. Create a virtual environment
2. Install dependencies
3. Run migrations
4. Start the development server

## Run
python manage.py runserver
